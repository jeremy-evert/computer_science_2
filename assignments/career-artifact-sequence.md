# Reusable assignment type: career artifact sequence

**Historical basis:** Dream Job, transcript/progress report/degree plan, resume, gap analysis, GitHub, LinkedIn, and LinkedIn Learning tasks recur from 2021 or 2022 through 2025; spring 2026 formalizes them as A01–A06.

Use as a modular sequence: inspect academic record, plan remaining semesters, draft a resume, research a target role, identify skill gaps, and build professional evidence. Each artifact should include a short reflection and a file naming/submission convention.

**Variation:** Some terms use a single Dream Job project; later terms split the work into separate submissions and add networking/learning tasks. Keep this outside the programming grade unless the syllabus says otherwise.
