# Reusable assignment: chapter coding practice

**Historical basis:** recurring chapter assignments in 2021–2026; the clearest recent form is “3 problems + mini-report.”

## Student task

Solve three problems from the current chapter, or substitute a clearly related problem of your own design. Submit one document with, for each problem:

1. Code.
2. Run results (screenshot or pasted output).
3. A brief reflection on the approach, obstacle, or next improvement.

## Assessment pattern

Use progressive credit: meaningful attempt; one working solution; two; three. Award most points for correct working code, with smaller points for evidence and reflection. Optional extensions may reward improvement, an explanation video, or a repository link.

## Semester variation

Earlier versions bundle many zyBooks labs under a chapter number, sometimes as “Programming HW.” Fall 2024–25 add pair-programming and “Coding Quest” variants. Keep those as optional variants rather than changing the core template.
