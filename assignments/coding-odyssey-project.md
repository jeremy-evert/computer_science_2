# Reusable assignment: Coding Odyssey / CYOAG project

**Historical basis:** CYOAG in 2022–23; Coding Odyssey in 2024–26; related open projects in earlier semesters.

## Student task

Design and build a project of choice: game, utility, simulation, or another useful program. The project should demonstrate an appropriate selection of course tools—control flow, functions, collections, classes, files, exceptions, and (where useful) plotting or a GUI.

Submit an idea/design, incremental working code, run evidence, and a short explanation or presentation. Keep the scope achievable and name collaborators/tools used.

## Assessment pattern

Progressive milestones historically range from design, to partial code, to running code, with bonus/qualitative credit for creativity, efficiency, enjoyment, clean code, or a presentation.

## Semester variation

The name, number of iterations, and final-project framing changed. Some terms used three Coding Odysseys; others used CYOAG stages or a final review project. Preserve the project choice and progressive-credit shape, not a semester-specific point schedule.
