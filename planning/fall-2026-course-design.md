# COMSC-1053 Fall 2026 course design

## Active source of truth

Computer Science II continues COMSC-1033. Students arrive able to read,
change, and test small Python programs with functions, collections, and
introductory classes. Fall 2026 advances them through intentional object
design, collaboration, data abstractions, honest data visualization and
storytelling, a modest event-driven interface, and a reviewable professional
workflow. The Reasoning Odyssey is the required
authentic programming spine; it is a fresh CS2-native world, not a CS1 code
continuation or a second weekly homework track.

The active resource hierarchy is course-owned work and shared Week 1/2
sources first; official Python documentation, direct Runestone/PyDS3 links,
CS1 refresh references, GitHub Docs/Skills, and Docker documentation are
recommended no-cost references. ZyBooks and Deitel are optional historical
or control references only, never required student dependencies.

## Course-priority enrichment

**S09 — Data visualization and storytelling** is a course-priority
enrichment, not an additional catalog claim. A student starts with authentic
program/project data and a stated question; chooses a defensible, readable
representation with labels and context; avoids misleading scale or encoding
choices; explains the supported takeaway in plain language; names a
limitation, uncertainty, or alternative interpretation; and connects the
evidence to a design, operational, or project decision. Weeks 11–12 give this
priority more instructional weight than the compact Week-10 GUI experience.
