# Week 4 — Cohesive Object Boundary (S01)

**Monday holiday — Labor Day.** There is no Monday class on September 7. Use
the Monday bridge to reopen your Week 3 World Bible, choose one predicted
object, and prepare the smallest boundary question you can test on Wednesday.

## Weekly focus

Reopen the [Week 3 World Bible gate]({{link:week03_odyssey_gate}}), choose one
candidate object from its predicted nouns, and test whether it actually
deserves a cohesive boundary. Build meaningful state and behavior only when
the evidence supports that boundary; a prediction that does not hold up is a
legitimate finding, not a failure. Write one small independent `unittest`
test and explain what it proves and what it does not prove.

Read the [Week 4 lesson]({{link:week04_lesson}}), then complete the [Week 4
Odyssey gate]({{link:week04_odyssey_gate}}). The [Week 4 rubric]({{link:week04_odyssey_rubric}})
is the scoring contract.

## Student path

| Day | Center | Student evidence |
|---|---|---|
| Wednesday | Reopen and test one prediction | candidate noun, responsibility/boundary notes, smallest object diff |
| Friday | Verify and defend the boundary | independently run `unittest`, result, one-sentence World Bible update |

Keep the AI Fluency connection explicit: if AI helps, save the request,
inspect the proposal and diff, read the changed code, run the test yourself,
and record an evidence-based accept/reject decision. The test—not the AI's
claim—proves the behavior.
