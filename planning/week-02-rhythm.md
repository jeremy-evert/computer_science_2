# CS2 Week 2 rhythm map

The Local AI bench remains the technical center. These named objects make the
shared seven-beat rhythm visible without turning Week 2 into a second graded
Odyssey build.

| Beat | Object and path | Evidence |
|---|---|---|
| Monday AI Fluency | Define the machine question before using a tool | one bounded claim and evidence plan |
| Monday Local AI Lab | `planning/week-02-local-ai-lab-integration.md` | readiness artifact |
| Wednesday Professional Minds | Make It Stick: explain one retrieval/learning idea in the lab context | short reflection in the Week 2 readiness record |
| Wednesday Paired Reasoning | compare a bounded AI coding proposal with a partner's independent check | claim/evidence/limit note |
| Friday Professional Minds | Mindset: revise one response to evidence or failure | final reflection |
| Friday Show and Tell Reporting | show the bounded change, test, and accept/reject decision | readiness reflection |
| Sunday Reasoning Odyssey Pulse | three-part claim/evidence/next-step pulse; light and ungraded | pulse note attached to the Week 2 readiness artifact |

Canonical technical source remains the shared Local AI Lab. CS2 owns this
sequence and its evidence wrapper; it does not claim a new Week 2 gate.
