# Monday Moments — Computer Science 2

A short, weekly tip-of-the-week for working with AI, scoped to CS2: data structures, recursion, and the first real algorithmic thinking.

**Engagement level for this course: AI as debugging partner and code reviewer.**

Students here can read and reason about code well enough to evaluate an AI's suggestion, not just accept it. The moments here build that muscle:
- Using an LLM to explain *why* a data structure choice is slow, then verifying the explanation against Big-O reasoning covered in class.
- Asking AI to review a recursive function for edge cases, then checking its review against a hand-traced example.
- Using AI to generate test cases for a function, then checking whether the tests actually cover the tricky inputs.
- Recognizing confident-sounding AI explanations of complexity or correctness that are simply wrong — this is the year students start catching those.

Add one entry per week using `template.md`.
