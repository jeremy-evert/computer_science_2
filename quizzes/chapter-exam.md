# Reusable quiz type: chapter exam

**Historical basis:** ten chapter exams in spring 2021 (Chapters 6, 7, 9, 10, 11, 12, 13, 17, 18, 20).

Use a short chapter-aligned quiz/exam with code reading, tracing, vocabulary, and a small implementation or debugging item. The archive confirms this type strongly for spring 2021 but not in later snapshots, so treat it as an optional assessment rather than a durable weekly requirement.
