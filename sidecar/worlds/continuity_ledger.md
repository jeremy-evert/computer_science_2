# Continuity Ledger

Internal canon. The living memory of the four worlds. **Consult before
writing any new world material.** Add an entry in the same commit that
introduces a new named character, location, artifact, or unresolved
thread -- do not let canon exist only in someone's head (that is,
notably, the exact failure mode every one of the four worlds' premises
is built around).

## Entry format

```
### [World] -- [short title]
- **Introduced:** [prompt/date]
- **Characters involved:** [names]
- **What happened:** [1-3 sentences]
- **What students learned / experienced:** [if applicable, or "N/A -- internal only"]
- **Software/world decision affected:** [if applicable]
- **Unresolved thread:** [what's left open, if anything]
- **Safe to return?** [yes / not yet / needs review]
```

An entry with no unresolved thread is still worth keeping -- it is the
record that lets a future author avoid contradicting something already
established.
