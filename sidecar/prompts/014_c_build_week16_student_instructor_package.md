# Prompt 014C — Build the CS2 Week 16 student/instructor package

**Status:** WAITING ON 014B GREEN  
**Parent:** Prompt 014

## Mission

Turn the implemented experiment bench into a polished Week 16 experience at the same finish level as CS1 while keeping the student burden small.

## Required artifacts

- student lesson;
- instructor guide;
- short experiment/design receipt;
- saved sample/fallback result data;
- honest plot path from real JSON/CSV evidence;
- updated `planning/week-16.md`;
- minimal Week 16 gate/rubric reconciliation.

## Student flow

1. run/trust baseline;
2. identify the strategy contract;
3. choose two fixed strategy/configuration options;
4. predict effectiveness, preparation cost, runtime cost, and software complexity;
5. run one bounded deterministic experiment bundle;
6. save evidence;
7. generate/read one honest chart;
8. decide which design should ship for a declared objective and why.

## Course-flavor acceptance

The package should naturally echo contracts/swappable collaborators, composition, experiment data abstractions, ordering by different objectives, honest visualization/storytelling, testing/review, and reproducibility.

Do not force every CS2 topic into the lab.

## Scope fence

No Checkpoint 4, formal RL math, giant report, required container/GPU/cloud path, or second Farkle engine.

## Receipt

Record the authored files, sample data provenance, expected student runtime/friction, and any deliberate omissions under `sidecar/runs/`.
