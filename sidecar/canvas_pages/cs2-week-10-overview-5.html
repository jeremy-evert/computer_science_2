Monday's lesson: Event-Driven Programming (Tkinter and a web page)

The idea is event-driven programming: an event happens, a handler runs, the model changes state, and the display refreshes. Tkinter is one front end and a web page is another; the logic underneath is the same. Python setup trouble is not the lesson.
