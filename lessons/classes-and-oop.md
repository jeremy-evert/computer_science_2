# Classes and object-oriented design

**Historical place:** Chapter 9, commonly split into Round 1 and Round 2.

**Objectives:** model a problem with classes; define constructors and methods; distinguish object state from behavior; use multiple objects.

**Key content:** attributes, methods, `self`, constructors, class responsibilities, simple class diagrams, testing object behavior.

**Historical materials:** vending machine, artwork label, instrument, and other zyBooks labs; repeated chapter and pair-programming assignments.
