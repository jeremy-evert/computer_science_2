# Strings, lists, and dictionaries

**Historical place:** Chapter 7 strings appears often; Chapter 8 lists/dictionaries is especially stable from 2023 onward.

**Objectives:** process text; select a collection; traverse and update collections; use dictionaries for keyed data.

**Key content:** indexing/slicing, loops, list mutation, dictionary lookup/update, frequency counting, input/output evidence.

**Historical materials:** zyBooks chapter labs, “word frequencies,” text analyzers, and weekly three-problem practice. Some semesters omit or rename Chapter 7.
