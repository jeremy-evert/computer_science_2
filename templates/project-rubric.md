# Project rubric template

| Criterion | Beginning | Developing | Working | Extending |
|---|---|---|---|---|
| Design/scope | idea emerging | plan identifies parts | achievable plan | thoughtful tradeoffs |
| Functionality | meaningful attempt | partial code runs | core behavior works | robust edge cases |
| Course tools | limited selection | some relevant tools | appropriate breadth | purposeful design |
| Explanation | minimal evidence | describes process | demonstrates and explains | reflects on improvements |

Adapt point values to the semester. Historical project rubrics used progressive milestones and qualitative bonuses; do not silently turn this into a fixed universal scale.
