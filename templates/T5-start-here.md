# Start Here

Welcome to COMSC-1053 — Computer Science II. {{TERM_LINE}}

## What this class is

You will extend working Python knowledge into object design, data
abstractions, GUI/event paths, honest visualization, and reviewable
professional workflow. The Reasoning Odyssey is one continuing project: each
week asks for bounded technical evidence, an explanation, and a record of
what remains uncertain.

## The weekly rhythm

| Friday | Shared Professional Minds | Show-and-Tell, A4, and A7 |
