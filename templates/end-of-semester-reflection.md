# End-of-semester reflection template

Choose five prompts (or more if useful):

- What skill changed most for you?
- Which problem or project taught you the most?
- Where did you get stuck, and how did you recover?
- What would you improve in your code or workflow?
- What course practice should continue?
- What are you curious to learn next?

Submit honest answers and one personal detail, quote, or image that represents the semester. This preserves the archived low-stakes, choice-based framing; set current privacy and grading expectations explicitly.
