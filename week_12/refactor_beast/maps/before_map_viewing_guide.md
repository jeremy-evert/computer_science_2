# Viewing the Before Map

`maps/before_map.md` contains two Mermaid flowcharts. To view them rendered with nodes, arrows, and colors:

1. Open this repository in Visual Studio Code.
2. Install a Markdown preview extension that supports Mermaid diagrams, such as **Markdown Preview Mermaid Support**.
3. Open `maps/before_map.md`.
4. Open Markdown Preview with **Ctrl+Shift+V**, or use the Command Palette and choose **Markdown: Open Preview**.

GitHub also renders Mermaid blocks when you view `maps/before_map.md` in the repository. The Mermaid source is regular Markdown and remains editable in the text editor.
