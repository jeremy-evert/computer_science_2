◈ ScriptBridge
Browser edition · Basic checks
This browser edition does not have every feature of the Windows version. GitHub Pages cannot run the local Ruff helper, so Python checks here are basic, not full linting. File editing and checks happen in your browser; ScriptBridge does not send your code to GitHub. For Ruff Python linting, use the Windows version.
Quick start
  1. Open or paste a script in the editor.
  2. Select the script file with Open existing script…, or choose where to save with Choose file to save….
  3. Click Paste / review AI script to open Review proposed change, then click Check script for basic checks.
  4. To use an AI update, copy the request, paste the complete reply in the review area, compare it, then accept or reject.
  5. Click Save now or enable automatic updates. A recovery copy is kept in this browser before each save.
