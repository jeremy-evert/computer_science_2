About Me

I teach Computer Science at Southwestern Oklahoma State University in Weatherford, OK. This page lives inside the CS2 course repository and doubles as the example of what a contributor page looks like. If you are a student, yours should look something like this.

What This Course Is About

CS2 (COMSC-1053) is organized around the Reasoning Odyssey: a semester-long arc covering object boundaries, composition and inheritance, contracts, data abstractions, GUI and event work, data visualization and storytelling, and professional workflow. The goal is not just to write code. It is to think like an engineer.

How to Make Your Own Page

  1. Clone the repo: git clone https://github.com/jeremy-evert/computer_science_2.git
  2. Go in: cd computer_science_2
  3. Copy this file: cp jevertj.html smithj.html
  4. Open smithj.html in your editor and make it yours.
  5. Stage it: git add smithj.html
  6. Commit it: git commit -m "Add smithj personal page"
  7. Push it: git push
  8. Add your card to index.html in the Student Pages section and push again.
