# Syllabus sources

This directory holds provenance and starting material for the COMSC 1053 syllabus.

The historical/template Word file here is **not** the Fall 2026 authority. It may contain stale rooms, times, textbook requirements, grading rules, attendance rules, or course sequencing. The active syllabus must be reconciled against current repository truth before publication.

Shared university/template sources are kept in `jeremy-evert/swosu_cs_curriculum/shared/syllabus_sources/` to avoid creating six independent copies of the same institutional policy source.
