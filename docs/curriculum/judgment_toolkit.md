# Judgment-building toolkit

Reasoning Odyssey uses small capability gates, design review, and a living World
Bible to make student judgment visible without creating duplicate homework.

| Instrument | Role |
|---|---|
| Capability gate | bounded build/change plus test/trace and design explanation |
| AI accountability | when AI is used: proposal, diff, independent test, read/reason, accept/reject |
| Micro-practice | short in-class/pair/optional repetition; never a parallel required problem set |
| Review | Weeks 13–15 peer/design/professional workflow evidence |
| World Bible | compact ongoing record of change, evidence, debt, and decisions |

A gate assesses real capability, not genre decoration. Week 12 accepts a
meaningful refinement; recursion/linked/nested structures are only one route.
Weeks 13–14 culminate creative construction; Week 15 is history, recovery,
collaboration, review, and bounded reproducibility. Week 16 has no Reasoning Odyssey
checkpoint and Week 17 has no technical final.
